# GarageHub

GarageHub is a full-stack web application for managing vehicles, maintenance history, fuel consumption, modifications and expenses.

## Technologies

- Angular
- TypeScript
- Node.js
- Express.js
- MySQL
- Angular Material

## Features

- Authentication
- Vehicle Management
- Maintenance Tracking
- Fuel Consumption
- Expense Dashboard
- Modification History
- Photo Gallery
